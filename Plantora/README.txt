PLANTORA WEBSITE
================

Pages:
- index.html       Long scrollable Home page
- about.html       About / Story / Mission
- services.html    Plant Care / Guides
- shop.html        Product catalog with filters and cart feedback
- contact.html     Contact form and map

Assets are stored in /images.

Open index.html in VS Code / Live Server to preview.
No backend is required for the demo interactions.
